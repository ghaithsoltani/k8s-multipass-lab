# Kubernetes Learning Lab — Multipass Edition

A hands-on Kubernetes project built on local Ubuntu VMs using Multipass.
No cloud provider needed.

## Structure

| Phase | Topic |
|-------|-------|
| phase-1-foundation | K8s concepts + cluster setup |
| phase-2-core-skills | kubectl, YAML, MongoDB demo |
| phase-3-networking | Namespaces, Services, Ingress |
| phase-4-storage-config | Volumes, ConfigMap, Secret, StatefulSet |
| phase-5-advanced-tools | Helm, Operators, RBAC |
| phase-6-production | Microservices, Helmfile, best practices |

## Setup

Built with: Multipass + K3s + kubectl on Linux.

Each phase folder contains its own README with step-by-step instructions
and all YAML manifests used.
